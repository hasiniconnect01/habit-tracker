# Command-Line Habit Tracker

A simple Python command-line application that helps users create habits,
complete daily check-ins, track streaks, and store progress locally.

## Features

- Add a new habit
- Add a description for each habit
- Mark habits as completed for the current day
- View current streaks
- View total completed days
- Store habit data locally using JSON
- Data remains saved after restarting the application

## Technologies Used

- Python
- JSON
